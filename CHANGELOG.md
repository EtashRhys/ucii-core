# 0.1.0 - Initial Public Release

Initial public release of UCII Core.

Included:

- identity primitives
- identity lifecycle models
- credential structures
- credential verification foundations
- post-quantum cryptographic foundations
- hybrid cryptographic components
- sandbox reference environment
- developer examples
- documentation and contribution guidelines

Architecture:

UCII Core represents the open identity foundation.

Operational systems, hosted services, and private infrastructure remain separate.
